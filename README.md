# WindyGI

Comparison sheets of WindyGI (UE 4.27) against Lumen (UE 5.8) and the UE 5.8 path tracer, served with GitHub Pages.

- `hw/`: WindyGI Hardware (ray-traced) against Lumen HWRT, RX 9070 XT at 4K.
- `sw/`: WindyGI Software against Lumen SW.

The pages are static: `index.html` with the data embedded and WebP images under `img/`.
